# dsh-tool-mc-bootstrap

English | [中文](README.zh.md)

Model-facing `bootstrap_mc_project` creates a complete minimal supported Fabric or NeoForge Java project in an empty directory from a pinned template contract, checks Java availability, and returns phase-structured evidence. Writes go through the session filesystem and never leave the workspace. It never overwrites a non-empty directory or claims gameplay or Gradle verification.
