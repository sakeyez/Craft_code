# Minecraft 工作台宿主

[English](README.md) | 中文

Minecraft 工作台管理开发进程、保留日志、依赖事务及只读依赖源码。[工作台界面](../../client/ui-mcmod-workbench/README.zh.md) 通过仅限回环访问的 `/mc-workbench` RPC 调用这些能力。支持现有 Minecraft 1.20.1–1.21.x 范围内的标准单项目 Fabric 和 NeoForge Java 工作区。

<a id="environment-and-runs"></a>

## 环境与运行

宿主通过 `tool-mc-project` 发现项目事实，验证 Java 主版本并使用项目的 Gradle Wrapper。环境准备复用兼容的已安装 JDK，或下载并校验官方 Adoptium 发布的 SHA-256。Java 设置仅用于子进程。新建模组向导复用此准备能力。

开发操作通过项目 Wrapper 独立运行。启动只执行发现的客户端／服务端任务及其 Gradle 依赖；资源校验、测试、构建和 datagen 保持独立。准备操作执行所选客户端 JavaExec 任务的实际依赖，解析类路径与参数 provider，记录已验证输入，不执行游戏任务。不支持的任务类型会阻止准备，但不阻止直接启动。准备成功不证明离线启动或玩法通过。开发模式的离线选项向 Gradle 传递 `--offline` 并禁止 JDK 下载，不断开系统网络，也不能限制任意插件或游戏自己的网络请求。

`.dsh/environment.json` 保存 Gradle User Home、验证过的 JDK 路径、构建／环境指纹及已发现任务。新建模组构建器将缓存位置写入此记录，后续工作台操作复用同一批下载。构建输入变化会使选择和任务发现缓存失效，不删除 Gradle 缓存。已选 JDK 缺失会阻止运行。项目 daemon JVM 条件和用户目录 Java 属性遵循 Gradle 优先级。准备与构建复用兼容 daemon；游戏运行使用所属单次 daemon，取消不会针对共享 daemon。损坏的 Loom 清单可从结构有效且指向官方元数据的本地副本恢复；保留损坏原文，不删除锁。

每个项目同时只运行一个操作。快照与完整捕获输出保存在 `.dsh/runs/<id>/`；日志游标使用 UTF-8 字节偏移。退出等待输出排空，取消终止进程树，宿主重启后将旧活动任务标记为中断。退出后仍可访问原始文件。

## 依赖事务

Modrinth 结果按检测到的游戏版本与加载器筛选。递归解析发布记录中的必需前置，并验证文件哈希。Maven 坐标和本地 JAR 读取实际归档元数据，无法确认的兼容性保持明确。必需依赖参与编译、开发运行和成品声明；可选依赖可在不安装时编译，并有测试安装开关；仅测试依赖只影响开发运行。

预览列出管理的文件、依赖关系及每个修改文件。应用时检查原始文件版本，并对 Gradle、元数据和锁定文件修改记录事务日志。中断事务在后续读取前恢复，外部修改的文件会阻止恢复。移除只删除本服务管理且不再被引用的哈希命名文件。动态或不支持的 Gradle 布局需要人工协助。

## 文件与源码

项目文件操作拒绝路径越界和符号链接。UTF-8 文本编辑限制为 2 MiB；保存时检查读取版本后再替换磁盘文件。没有外部写入者配合，无法排除其恰在最终文件系统重命名时并发写入。

匹配的 Maven 源码包或明确关联的归档优先于 Vineflower 1.11.1。反编译引擎下载固定 SHA-256。源码缓存标识输入文件和源码／引擎哈希，复用前验证缓存内容，并保持只读。不猜测或转换映射名称。失败或取消的反编译不会发布就绪缓存。

## 下载与构建网络

宿主通过设置服务保存 `minecraft-network` 偏好：自动（默认）、直连或自定义 HTTP/HTTPS 代理。`/mc-workbench` 的 `network-get`、`network-save`、`network-check` 不要求打开项目。操作启动时固定配置；修改设置会清除五分钟成功路径缓存，并用于后续操作。

自动下载优先直连具有明确来源映射的国内镜像，再通过已检测代理或直连访问官方源。Electron 通过私有子进程通道解析系统代理；其他宿主使用受信任的进程／用户启动环境代理。TUN 路由由操作系统管理。自定义模式不会切换到直连。凭据、SOCKS 和 PAC 地址会被拒绝；HTTPS 代理可用于 Node 下载，Java 则要求 HTTP／混合端口，并明确报告不兼容。

下载有超时、取消、有限重试（每条路径三次）、大小限制，以及发布方提供的哈希校验。已验证下载原子写入缓存；JDK 发行信息和校验来源保持官方。Gradle 接收子进程 JVM 代理属性和本地地址绕过规则。开发操作保留项目仓库与 Loom 地址；成品安装和新建项目可使用应用托管的镜像初始化脚本。不改写任意仓库地址或全局 Gradle 设置。明确网络故障可在原始时限内使用官方源重试，自动模式还可尝试直连；编译错误和取消不重试。保留已验证缓存，不使用 `--refresh-dependencies`。

## 成品测试与证据

开发模式使用已发现的项目任务。成品模式先构建，根据 Gradle 输出和 JAR 元数据验收唯一发布产物，再通过 MIT 许可的 `@xmcl/core@2.15.1` 与 `@xmcl/installer@6.1.2` 安装精确的 Minecraft／加载器版本。已校验游戏资源共享缓存；客户端与服务端的存档、配置和模组分别保存在 `.dsh/instances`。受管文件替换前校验必需依赖、哈希、运行侧及不兼容关系，并记录事务。EULA 单独接受。进程启动、世界就绪与玩法结果是不同证据；未经明确测试的玩法保持未验证。

运行记录格式 4 保留有限步骤、下载进度、失败分类、可重试状态、模式和产物证据。旧记录缺失的证据保持未知；旧格式客户端的世界就绪时间不再作为证明，因为进度数据可在世界启动前加载。重试会重新检查项目输入及缓存并创建新操作；宿主重启不会启动游戏。Gradle、编译及游戏 JVM 分别记录选择依据。流式下载使用增量哈希、临时文件身份和 Range 校验；并发调用者共用传输但独立取消。

## 恢复、API 与导出

`./tools` 消费插件注册 `query_mc_api`，并在每个 Minecraft 会话轮次首次修改或 shell 工具前建立完整恢复点。依赖提交另建恢复点。内容寻址快照排除凭据、Git 内部目录、缓存和实例，保留二十个自动记录；手动记录由用户删除。恢复预览将文件差异绑定到当前版本，先保存当前状态再记录替换事务；备份不完整和外部修改会阻止被保护操作。

API 查询验证最近构建的输入与 classpath 哈希，返回精确版本、命名空间和来源，并复用匹配源码及反编译缓存。未知或冲突的 mappings 及可选 mappings.dev 结果保持未验证。PNG 与有限原版模型预览解析本地或已校验的精确版本原版资源；动画和自定义渲染不受支持。草稿仍由编辑器管理，生成资源保持只读；文本搜索只定位候选生成器。

CurseForge 与 Modrinth、Maven、本地文件共用依赖预览及提交。`CURSEFORGE_API_KEY` 由凭据服务管理。发布方项目／文件 ID 和 SHA-1 标识下载；受限文件提供来源页面和本地导入。跨来源 mod ID 会被检查，不按名称合并。导出重新验证源码及产物哈希，输出 JAR、SHA-256 和简洁记录，保留未知的运行及玩法证据。

## 模型体验

### 选择的工作台证据

#### 模型可见内容

`/mc-workbench` RPC 和日志不会追加模型上下文。授权后的运行检查通过已挂载的 shell 使用现有 run_mc_check 工具；结果标识保留日志的位置，不自动插入日志内容。用户选择的代码、依赖事实和日志片段由界面通过普通会话消息发送。

#### Token 影响

只有明确发送的片段和请求的检查结果增加 token；后台轮询不增加。

#### KV Cache 影响

导航、轮询和日志收集没有影响。明确发送的片段与其他用户消息一样扩展会话前缀。

## 已知限制与暂缓事项

- Maven POM 传递依赖、任意动态 Gradle 脚本和未知映射需要人工协助。元数据无法建立兼容性时，本地文件保持未验证。原版客户端停留在标题画面时可能一直显示运行中，直到出现世界加载证据。自动化浏览器和文件系统测试不能证明真实玩法；实际加载器构建及经授权的启动提供独立证据。
