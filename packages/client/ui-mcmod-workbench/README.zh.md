# Minecraft 工作台界面

[English](README.md) | 中文

本插件在应用菜单同排提供代码、前置与联动和游戏测试入口。打开任意侧栏会话（包括当前会话）都会返回对话。测试页保留日志控制台，Minecraft 下载设置位于应用设置中。开发控件无需连接 IDE。窄窗口可横向滚动导航。宿主拥有后台操作；客户端跨页面保留草稿、文档和日志位置。

## 交互

游戏测试页在启动前即可进入，显示检测到的环境事实、准备／构建／客户端／服务端控件、停止及保留的运行记录。日志支持搜索、错误筛选、跟随控制、复制、导出和打开原始文件。只有明确点击发送，日志内容才进入助手上下文。

依赖页提供 Modrinth 搜索、Maven 坐标和本地 JAR 导入。变更先展示文件预览。每个依赖均可浏览源码，并通过普通会话消息交给助手编写联动。

代码页在同源框架中按需加载本地打包的 Monaco，提供文件树、文档标签、文本搜索、磁盘／HEAD 差异和带版本校验的保存。只读源码标签不能保存。解释、修改和排错操作包含路径、选中行号、实际文本及草稿来源。

成品／开发选择保留在游戏测试页；状态默认显示当前步骤，详情折叠。PNG／模型预览和精确版本 API 查询位于代码页。恢复点与导出使用项目菜单，CurseForge 使用现有依赖来源选择器。恢复预览在文本大小允许时显示当前与目标内容。关于入口链接应用许可证、第三方声明和源码仓库；生成的模组自行选择许可证。

## 模型体验

### 选择的工作台证据

#### 模型可见内容

导航和编辑没有影响。明确交给助手的操作通过 `session.prompt` 追加普通用户消息，其中包含选择的证据和当前项目事实；后台日志不会自动加入。

#### Token 影响

只有明确发送的片段和请求的检查结果增加 token；后台轮询不增加。

#### KV Cache 影响

只有发送的消息改变会话前缀。Monaco、源码浏览和保留日志不会改变模型请求。

## 已知限制与暂缓事项

- 草稿在当前应用实例的页面／项目切换间保留。Java 语义补全、断点、二进制编辑和可编辑反编译项目不在此编辑器范围内。大文件使用外部工具处理。源码映射的不确定性沿用宿主来源标识，不推测名称。
