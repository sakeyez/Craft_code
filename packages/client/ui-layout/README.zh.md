# @deepseek-ai/dsh-client-ui-layout

[English](README.md) | 中文

外壳插件：三栏 AppFrame（拖动手柄与让步链）加 `ctx.layout` 面板服务和外部游戏状态／标注入口。它注册到运行时拥有的 `root` slot，并声明各栏、顶栏、工作台和覆盖层插槽。

AppFrame 始终挂载对话栏和详情栏。瞬时布局 store 只管理 renderer 几何，不读写 `localStorage`。Minecraft 连接后，顶栏、侧栏、详情栏、对话、模型选择和输入框继续挂载且可交互。

所选项目的 `game` slot 只显示游戏名称、连接状态、被动错误和一个标注入口。Minecraft 在所有桌面平台都保持独立顶层窗口；游戏移动、最小化或恢复不会让 CraftCode 隐藏、调整大小、重新定位、最大化或改变后台节流。点击标注后创建一次性无边框覆盖层，只冻结画面，不挂起 Minecraft。

提交瞬间解析当前会话，因此标注期间可以切换会话。当前会话无效、不可保存或编号冲突时返回错误，并保持覆盖层和草稿；成功后才关闭并重置事务。快捷键和页面按钮共用同一个操作编号，迟到消息和窗口身份校验不会影响新事务。

游戏 slot 不包含聊天、重新定位或重连控件。已保存标注归属于完成提交瞬间的当前会话；原生 HWND 和捕获权限只保留在主进程。

布局通过显式客户端会话导航切回目标项目的对话页面，重复打开当前会话也会生效。工作台面板保持挂载，因此草稿与日志位置会保留；后台执行状态仍由宿主拥有。

## 模型体验

无。布局外壳管理浏览器查看状态；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **面板几何信息是瞬时状态**：重新加载恢复默认侧栏宽度并关闭详情栏；切换不同会话时详情栏会在绘制前关闭。
- **外部游戏跟踪依赖桌面宿主**：浏览器会话不会获得特权游戏窗口操作，非 Windows 宿主也保持 Minecraft 独立窗口。

顶栏将 `shell.topbar`、`workbench.nav` 和 `shell.window-controls` 排在同一行；空插槽不占空间。桌面宿主管理末尾拖拽区和窗口按钮。布局声明[ Minecraft 工作台](../ui-mcmod-workbench/README.zh.md)的项目导航及页面插槽；显示项目工具时仍保留对话子树。
