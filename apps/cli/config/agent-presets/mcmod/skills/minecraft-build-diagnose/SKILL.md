# Minecraft Build Diagnosis
Use real `run_mc_check` or Gradle output. Classify environment, dependency resolution, Java compilation, resource, datagen, test, and runtime failures separately. Give evidence-based next actions and never describe static checks or a successful build as gameplay validation.
