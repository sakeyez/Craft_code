# Minecraft Environment Doctor
Diagnose the actual bootstrap or Gradle result. Classify Java availability/version, wrapper/dependency, cache, permission, template, and code failures. Reuse valid caches and environment settings; do not repeatedly guess versions or rewrite Gradle files without evidence.
